# Trucker Job System

A modern trucker job system with multiple freights and a user-friendly UI.

## Features

- Multiple freights with different payment amounts
- Modern UI for selecting and tracking deliveries
- Job-specific blips and notifications

## Requirements

- FiveM server with ESX framework
- MySQL database

## Installation

1. Download the script from the [GitHub repository](https://github.com/EnderDevelopment/trucker-job-system).
2. Place the script in your FiveM server's `resources` folder.
3. Add the following line to your `server.cfg` file:

```
start trucker-job-system
```

## Usage

1. Players must have the trucker job to access the job menu.
2. Use the `/truckerjob` command to open the job menu.
3. Select a freight from the menu to start a delivery.
4. Navigate to the delivery location and press the interaction key to complete the delivery.

## Configuration

The script can be configured in the `config.lua` file. You can adjust the job settings, freight details, and UI elements to suit your server's needs.
